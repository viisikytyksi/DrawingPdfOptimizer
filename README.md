# 図面PDF 画像2値化

Version 0.8.2

CADのベクトル線・文字を保持したまま、PDF内の大きなラスター画像だけを明瞭化・A3向け解像度に縮小・1bit化するWindowsアプリです。

## 使い方

1. ZIPを展開し、`Start.exe` を起動します。フォルダー一式を共有フォルダー上に置いて実行することもできます。
2. `PDFを追加...` で対象ファイルを選ぶか、PDFをファイル一覧へドラッグ＆ドロップします。
3. 通常は `A3 / 300 dpi` のまま `最適化を開始` を押します。
4. 元ファイルと同じ場所に `元ファイル名_2値化.pdf` が作成されます。元PDFは変更しません。

PDFを `Start.exe` へ直接ドラッグ＆ドロップすると、A3・300dpiの既定設定で自動的に処理を開始します。複数PDFをまとめてドロップできます。`Start.cmd` はEXEが起動できない場合の予備ランチャーです。

元ファイルと同じ場所に書き込めない場合は、保存先としてデスクトップや一時フォルダーなど、書き込みできる場所を選択してください。一時フォルダーを使った場合は、確認後に成果物を本来の保存先へ移します。

## 既定動作

- PDFページ、CADベクトル、文字、注釈、しおりは維持します。
- PDFの作成者・タイトル等のDocument Info、XMPメタデータ、ファイルIDは削除します。
- 長辺1200px以上または100万画素以上の画像を背景画像とみなします。
- 寸法も面積も小さいロゴ・印影・写真は処理しません。
- A3全面を300dpiで印刷するのに必要な最大画素数へ縮小します。拡大はしません。
- Otsu法で自動しきい値を決め、1bitグレースケール画像としてPDFへ戻します。
- 既定で**ノイズ除去**を行います。1bit化した後に孤立した黒点と2画素のかたまりだけを消すので、細い線は残したまま、薄い青焼きスキャンの紙の地色・スキャンノイズを抑えます（処理時間は約1.5倍、ファイルは約15%小さくなります）。
- 画像の準備処理は最大2スレッドで並列化し、PDF Writerへの反映は直列化してPDF構造を保護します。
- 電子署名付きPDFは、保存によって署名が無効になります。

## 処理ログ（使用記録）

処理したPDFの記録を `DrawingPdfOptimizer.log`（CSV、Shift_JIS）へ1件1行で追記します。Excelでそのまま開けます。

- 保存先: 社内共有フォルダ。共有フォルダへ書けない場合はアプリのフォルダへ自動で切り替え、画面に新しい保存先を表示します。
- 実行ごとに `(実行開始)` と `(実行完了)` の行も残ります（完了行には入力件数・成功/失敗件数・合計所要秒・合計容量）。電源断などで途中終了した場合も、どこまで進んだかを追えます。
- 失敗したファイルも `status=error` として1行残ります。**1件失敗しても残りのPDFは処理を続けます**（失敗した分だけ出力がありません）。
- 記録項目: 日時、バージョン、ユーザー名、氏名、PC名、PDFのパス、ファイルサイズ、画像数（全体・変換・小画像スキップ・未対応スキップ）、処理後のサイズ、所要秒、dpi、結果（ok/error）、エラー内容
- 退避先にも書けなかった場合もPDFの処理は完了しますが、**画面に警告を表示します**。このとき記録は残っていないため、配布元へ連絡してください。
- 記録が残るのは `Start.exe`（画像2値化ツール）です。`Rasterize.exe` は記録しません。

## 調整の目安

- 線が薄い: `黒を増減` を右へ動かします。
- 汚れが黒く残る: `黒を増減` を左へ動かします。
- 容量をさらに小さくする: 200 dpiを選びます。
- 細い寸法線を優先する: 400 dpiを選びます。
- 小さな貼付画像も対象にする: `小さい画像も2値化する` をオンにします。カラー印影なども白黒になるため注意してください。
- 元PDFのメタデータを残す必要がある: `PDFメタデータを削除` をオフにします。ファイルを外部へ公開する用途ではオン推奨です。
- 背景がざらつく（薄い青焼きスキャン）: `ノイズ除去` は既定でオンです。点描・破線が細かすぎる図面ではオフにしてください。処理時間が約1.5倍になります。

## 制限

- ページ全面を画像化する方式ではありません。PDF内の画像XObjectだけを対象にします。
- PDFのインライン画像、特殊な画像形式、破損画像はスキップする場合があります。
- メタデータ削除はDocument Info、XMP、ファイルIDが対象です。注釈、添付ファイル、フォーム値、レイヤー名、非表示テキスト/OCRテキスト、描画済み文字列、ファイル名由来の情報は別途確認してください。
- 透過画像は白背景に合成して2値化します。
- PDF/AやPDF/Xの適合性、電子署名は再保存後に失われる場合があります。
- 初回は必ず複製したPDFで、線の欠け、画像位置、ページ数、印刷結果を確認してください。

## 開発者向け

変更したら、まず煙テストを実行します（pypdf と Pillow があれば動きます。同梱ランタイムでも可）。

```powershell
runtime\python.exe tools\smoke_test.py
```

GUIと同じ引数での実行、1件失敗しても残りを続けること、ログの退避、進捗イベントの到達を確認します。

単体EXEを作る場合はPython 3.14を使い、PowerShellで次を実行します。

```powershell
.\build.ps1
```

成果物は `dist\DrawingPdfOptimizer.exe` です。実行する側のPCへ、Pythonや追加ソフトをインストールする必要はありません。

ネットワークなしのポータブルフォルダーを作る場合は、pypdfとPillowが入ったPythonで次を実行します。

```powershell
python .\build_portable.py <出力フォルダー>
```

依存ライブラリ: pypdf (BSD-3-Clause)、Pillow (MIT-CMU)。

## ランタイムの再構成

このリポジトリには同梱ポータブルPythonランタイム（`runtime/`、約61MB）を含めていない。
配布物を作る場合は次の手順で用意する（要インターネット）。

1. python.org から **Windows embeddable package (64-bit)** を入手し、`runtime/` へ展開する
2. `python312._pth` の `#import site` のコメントを外す
3. get-pip.py で pip を導入し、`pypdf` と `Pillow` を `runtime/Lib/site-packages` へインストールする

配布時は `runtime/` を含めたフォルダ一式をzipにする。インターネットに接続できない、
または管理者権限が無いPCでも使えるよう、インストーラを使わずフォルダのコピーだけで動く形にしている。

## 全ページ画像化

ベクトル図形も含めてPDFの各ページを完全にラスタライズし、ページごとの1bit画像として保存する場合は `Rasterize.cmd` を起動します。

- 既定: 300dpi・1bit PNG
- Ghostscriptでページごとの1bit PNG（`pngmono`）またはTIFF（Group 4）を直接生成
- GUIまたはCLIでPNG/TIFFを選択可能
- GUIの `Slides用タイルPNG (1600px)` を有効にすると、Ghostscriptの1bit PNGを1600px以下のタイルへ分割し、`manifest.json`とともに保存。CLIでは `--tiles 1600` を指定
- 既定2並列。設定画面またはCLIで1/2/4並列を選択可能
- 入力PDFごとに `<PDF名>_画像化` フォルダーを作成
- Ghostscriptを `runtime\Ghostscript\bin\` に配置
- `runtime/` は `.gitignore` 対象で、Pythonと依存バイナリはGitへ登録しない
- Ghostscriptは実行ファイルだけでなく`Resource`等の実行に必要な最小フォルダーも配置する
- NAS上で使う場合も `Rasterize.cmd` を直接起動できます。内部でUNCパスを一時ドライブへ割り当てて処理します。

GhostscriptのPDF読み込みには実行に必要なDLLと`Resource`フォルダーが必要です。
